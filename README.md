#  Product Review Sentiment Analyzer

An AI-powered web application that analyzes customer reviews and predicts whether the sentiment is **Positive** or **Negative** using Machine Learning.

##  Features

- Predicts sentiment from user-entered reviews
- Interactive Streamlit web interface
- NLP-based text preprocessing
- Machine Learning prediction
- Fast and easy to use

---

##  Tech Stack

- Python
- Streamlit
- NLTK
- Scikit-learn
- Pandas
- NumPy

##  Installation

Clone the repository

```bash
git clone https://github.com/sahananr4/product-review-sentiment-analyzer.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
